# 先判定要不要后端

> 给个人制作者的「纯单机 0 元上线」教程：先判断你的项目需不需要后端，再决定要不要花钱。
> 1 份主报告 · 3 份单开文件 · 2 份底座 · 2 份附录 · 1 份免费层取样 · 1 份分支判定 · 3 本台账。
> 分支：`serverless`，长期独立主题分支；与 `vps` 分册两套独立文件系统，不做双向合并。

## 解决什么

**19.9 不是入场费，是「数据需要离开设备之后」的最低后端价。** 纯单机、零网络请求的小游戏与工具类小程序，可以 0 元完成备案与上架；一旦需要跨设备同步、权威排行榜、内购、UGC、远程配置或联机，就离开 0 元档，此时才需要比较各家后端。

读完你会得到：一张「要不要后端」的判定表、三条可照做的上线全流程、一份可自己按 URL 复核的证据清单、一份「选/不选 serverless」的代价对照、以及一份全量术语表。

## 三条硬规矩

1. **价格只引编号**：`_shared/价格快照-2026-11.md` 的 `S-001`~`S-199` 是唯一价格源，正文不抄第二份数值。`data-version: 2026-11-12.0`，跨月引用需重新核对。
2. **五档证据分层**：`【官网明确】` / `【官方社区·专员】` / `【开发者自述】` / `【推算】` / `【未查到·不确定】`。每个断言必带证据性质；冲突只登记 `UNK-NN`、不裁决、不写「以 X 为准」。
3. **编号空间隔离**：本分册的 `S-`/`FL-`/`UNK-`/`TERM-`/`DC-` 与 `vps` 分册的价格编号体系无映射、不互引、不双向合并。
