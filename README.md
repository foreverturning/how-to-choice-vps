# 先判定要不要后端

> 给个人制作者的「纯单机 0 元上线」教程：先判断你的项目需不需要后端，再决定要不要花钱。
> 分支：`serverless`，长期独立主题分支；与 `vps` 分册两套独立文件系统，不做双向合并。
> **规则不是铁板**：这套文档的规则本身能被质疑和修订，入口见 [元规则](_shared/00-元规则.md) 与 [规则索引](_shared/规则索引.md)。「信息不全面、覆盖面不够」就是有效质疑理由，不需要先举证。

## 解决什么

**19.9 不是入场费，是「数据需要离开设备之后」的最低后端价。** 纯单机、零网络请求的小游戏与工具类小程序，可以 0 元完成备案与上架；一旦需要跨设备同步、权威排行榜、内购、UGC、远程配置或联机，就离开 0 元档，此时才需要比较各家后端。

读完你会得到：一张「要不要后端」的判定表、三条可照做的上线全流程、一份可自己按 URL 复核的证据清单、一份「选/不选 serverless」的代价对照、一份全量术语表、以及一份能让规则本身被改的元规则。

## 三条硬规矩

> 这三条、以及本册其它规则，都受 [元规则](_shared/00-元规则.md) 约束：可开 `RQ-` 质疑、走 `CR-` 修订，不因「一直如此」被挡回。规则与可复核事实冲突时，改规则而不是否定事实。

1. **价格只引编号**：`_shared/价格快照-2026-11.md` 的 `S-001`~`S-249` 是唯一价格源，正文不抄第二份数值。唯一例外是 `flows/版本更新与热更新边界.md` §0 的体感表——它允许直写金额，但每格必须同时给 `S-` 编号。`data-version: 2026-11-12.1`，跨月引用需重新核对。
2. **五档证据分层**：`【官网明确】` / `【官方社区·专员】` / `【开发者自述】` / `【推算】` / `【未查到·不确定】`。每个断言必带证据性质；冲突只登记 `UNK-NN`、不裁决、不写「以 X 为准」。
3. **编号空间隔离**：本分册的 `S-`/`FL-`/`VU-`/`UNK-`/`TERM-`/`DC-`/`RQ-`/`CR-` 与 `vps` 分册的价格编号体系无映射、不互引、不双向合并。

## 维护者

- 数值改动：先登记 `ops/数据变更记录.md` → 版本 +1 → 列受影响文档清单 → 逐篇同步 → 回填回执。
- 术语改动：只改 `appendix/术语表.md`，其余文件只引 `TERM-xxx`。
- 新增来源：只改 `appendix/来源清单.md`，其余文件只引来源前缀编号。
- 规则质疑 / 修订：开 `RQ-` → 走 `CR-` → 列影响面逐篇同步 → 回填回执；纯规则改动不升 `data-version`（见 `_shared/00-元规则.md` §4）。
- 新增规则：先在 `_shared/规则索引.md` 登记一行，再改落点文件；改索引本身同样走 `CR-`。
- 取证日期统一 2026-11-12；按季度重扫免费层、冲突项与规则自身。
