# 云服务器到底贵在哪？

> 给 Vibe Coding 新手的「云服务器成本拆解 + 价格体检 + 省钱部署」教程。
> 8 篇文章 · 6 个实操 Lab · 5 份工具模板 · 1 份附录 · 3 份质检报告。
> 当前状态：P7 已完成并推送（`v1.0-draft`）；实际进度以 [ops/进度.md](ops/进度.md) 为准。

## 解决什么

判断「贵得合理」还是「便宜有坑」：**成本地板 × 合理毛利 = 合理价格区间**，再用三色灯评分卡验一台低价机。读完你会得到一张个人项目成本表、一套最低成本部署方案、一份价格体检报告和预算告警。

主线是：认知纠偏 → 算账 → 白嫖 → 省钱 → 成本解剖 → 选型 → 低价机专题 → 决策避坑。

## 三条硬规矩

1. **价格只引编号**：`_shared/价格快照-2026-11.md` 的 `P-001`～`P-054` 是唯一价格源；成本数字以 `_shared/三档成本模型.md` 为准。当前 `data-version: 2026-11-08.1`，跨月引用需重新核对。
2. **不点名**：低价机、转卖机、NAT 商家一律类型化描述；头部公有云仅在引用公开定价、财报、折旧年限时作为出处，不做推荐、不比较「谁更好」。
3. **改数据走台账**：先登记 `ops/数据变更记录.md` → 版本 +1 → 列受影响文档清单 → 逐篇同步 → 回填回执。不得绕过台账直接改数字（完整规则见 `ops/编排方案.md` 第 10 节）。
