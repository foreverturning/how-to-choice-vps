# 不选与选用 serverless 的代价

> 用途：核实「不选用 serverless」的三条常见理由是否成立，并列出选用后的完整后果。
> 用法：§1 看三条纠正 → §2 看修正后的真实理由 → §3 看后果清单 → §4 看因果对照 → §5 看四步不可逆 → §7 决策卡。
> 上游：`appendix/来源清单.md`（URL 与 `UNK-` 冲突）、`_shared/价格快照-2026-11.md`（`S-` 数值）、`cases/可查证示例与证据分层.md`（证据分层）。

## 0. 结论摘要

| 用户提出的理由 | 核实结论 | 本册怎么改 |
|---|---|---|
| 数据难迁移 | **不成立且因果颠倒** | 改列为「纯单机自身的代价」 |
| HW 云备案麻烦 | **部分成立但需重写** | 改写为「可备案资源清单未列函数类产品」 |
| 平台依赖 | **成立但需分层** | 改写为「少一层 BaaS 依赖，非零依赖」 |

**选用 serverless 的真实代价不在数据，而在能力层锁定、按环境计费、免费层到期与不可逆的单项规则。**【官网明确】+【推算】假设：以取样时点的官方条款为准。

## 1. 三条用户假设核实

### 1.1 「数据难迁移」不成立且因果颠倒

| 一侧 | 事实 | 证据性质 |
|---|---|---|
| 纯单机 | 本地键值存储按用户维度隔离，清缓存/卸载/换设备即失，官方接口集合只有读写清删，**没有批量导出** | 【官网明确】+【推算】 |
| BaaS | 官方提供数据库导出接口（JSON/CSV）、跨环境资源迁移文档、导出 JSON、CLI 数据转储 | 【官网明确】 |

平台锁定的是**能力层**：私有协议链路、`wx.cloud` SDK、OpenID 自动注入、免鉴权支付、资源点制切换后不可切回、环境销毁数据不可恢复、默认域名仅开发测试。这些是**能力**，不是数据文件。【官网明确】

需注意：跨环境迁移文档明确「不支持一键迁移，需逐模块手工迁移」，且索引与权限规则要在目标环境重建——这是**隐性迁出成本**，但仍不等于「数据不可迁出」。【官网明确】

**结论**：「数据难迁移」是纯单机自身的代价，应移到 §4 的「失去什么」列；把它写成「不选 serverless 的好处」属于因果颠倒。

### 1.2 「HW 云备案」部分成立但必须重写

成立的是**产品事实**：HW 云《准备可备案的服务器》官方表 1 只列六类可备案资源——ECS（含 Flexus X）、Flexus L、企业门户、专属云、公网 NAT 网关，且需包月≥3 个月或包年≥1 年；每台 ECS 可生成 5 个备案授权码，生成前提是绑定弹性公网 IP。**表中未列**函数工作流、API 网关、对象存储，也没有 Serverless 资源包或云函数资源包条目。因此只能写「**清单未列**」，不能写「不可备案、备案难」，见 `UNK-27`。【官网明确】

不成立的是「这是 HW 云独有」：备案是「境内主体 + 对外域名/公网服务」的**通用法规要求**，三家云的备案服务都免费。腾讯云 CloudBase 满足三条件（个人版及以上、剩余有效期 >6 个月、开启固定 IP）即可作为备案云资源；腾讯云 **SCF** 购买 5000 万次调用包与 40 万 GBs 资源用量包可备案 2 个服务；阿里云函数计算购买任意 CU 资源包可获备案服务码。**用户印象中的「买云函数资源包就能备案」是腾讯云 SCF 条款，不是 HW 云。**【官网明确】

另需分清两层：小程序备案（APP 备案）免费、个人只要身份证件，是所有小程序上架前必做；域名 ICP 备案才需要可备案的服务器或资源包。纯单机零网络请求不触发后者。【官网明确】

### 1.3 「平台依赖」成立但需分层

| 层 | 不选 serverless 是否仍依赖 | 说明 |
|---|---|---|
| 客户端运行时与 API | 是 | 小程序/小游戏框架本身 |
| 审核规则与服务类目 | 是 | 游戏类目一经选定不可变更 |
| 账号主体与实名 | 是 | 个人主体、认证状态 |
| 广告平台 | 是 | 变现仍走平台流量主/广告联盟 |
| BaaS 私有协议与 SDK | 否 | 这一层是唯一被省掉的 |
| 按环境计费与资源点制 | 否 | 无套餐、无额度、无欠费停服 |

**结论**：纯单机只是**少一层 BaaS 依赖**，不是零平台依赖。【官网明确】+【推算】

## 2. 修正后的「不选 serverless」真实理由（6 条）

| # | 理由 | 证据性质 |
|---|---|---|
| 1 | 不产生平台侧数据：数据只在用户设备，不受环境到期、隔离、销毁影响 | 【官网明确】+【推算】 |
| 2 | 不绑定按环境计费与资源点制：无套餐、无抵扣顺序、无欠费停服、无「切换后不可切回」 | 【官网明确】 |
| 3 | 无需备案域名与服务器（前提：不对外提供公网 Web 服务或绑定自定义域名） | 【官网明确】 |
| 4 | 无免费层到期与自动转按量风险：不上线后到期、不 6 个月一续、无停服销毁公告 | 【官网明确】 |
| 5 | 包体与本地存储即可满足：单机小游戏与工具类不需要为「万一要联网」预付后端 | 【官网明确】 |
| 6 | 主动接受单机数据易失，换取结构更简单、可离线运行 | 【推算】假设：项目命中第 0 章零维度 |

## 4. 因果对照表

| 选择 | 得到什么 | 失去什么 | 不可逆 / 隐性成本 |
|---|---|---|---|
| 纯单机 0 元 | 0 元、无服务器、无需备案域名、无平台侧数据 | 跨设备、好友榜、云存档、远程配置、不发版改内容 | 数据易失不可迁；仍依赖客户端与审核规则 |
| 平台代做能力 | 0 元拿到托管榜、关系链、云存档 | 数据结构与协议由平台定 | 游戏类目不可变更；能力不可带走 |
| 19.9 云开发 | 数据库、函数、存储、免鉴权支付、固定 IP、可备案 | 0 元不再；按环境计费；免费层到期 | 资源点制不可切回、环境销毁不可恢复、SLA 收窄、逐模块手工迁出 |
| 境外 0 元 BaaS | 0 元、标准协议、官方导出、无境内域名备案 | 境内访问延迟；无微信免鉴权能力 | 免费层可随时取消；不能承载境内主体小程序 |
| 第三方 BaaS「有条件 0 元」 | 数据库、云函数、厂商自有已备案域名（小程序形态免自备）、0 元开通 | 需每月手动续期、额度极小、超限停服、无 SLA；前端网页托管仍需域名备案 | 免费空间不续即释放；条款随时可变；不构成可持续付费档替代；只引 `S-250`~`S-271`、`UNK-52` |

## 5. 隐性后端触发器与四步不可逆

九维触发器（跨设备、权威榜、虚拟支付、广告服务端验证、UGC 过滤、远程配置、大资源超包体、联机对战、内容与资源热更新）逐条展开见主报告第 0 章与 `S-080`~`S-099`。平台已代做的能力见主报告 §5.2。

| # | 不可逆点 | 证据性质 |
|---|---|---|
| 1 | 游戏类目一经选定不可变更为其他小程序类目 | 【官网明确】 |
| 2 | 资源点计费模式切换后不支持切回原计费模式 | 【官网明确】 |
| 3 | 环境销毁后数据均不可恢复 | 【官网明确】 |
| 4 | 主体类型变更 | 【未查到·不确定】 |

## 6. 出局理由一句（供主报告 §1.1 逐字引用）

HW 云按量拆卖链路的最小计费单元与备案资源清单，都会把「先判定要不要后端」拉回「先买一台服务器」的旧框架，故不纳入本册的平台比较范围。【官网明确】+【推算】
