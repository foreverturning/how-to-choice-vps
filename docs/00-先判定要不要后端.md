# 先判定要不要后端

> 副题：纯单机 0 元上线 ｜ 19.9 不是入场费，是数据离开设备之后的最低后端价
> 证据图例：`【官网明确】`/`【官方社区·专员】`/`【开发者自述】`/`【推算】`/`【未查到·不确定】`，详见 [写作规范](../_shared/写作规范.md) 第二节。
> 复核提示：19.9 为取样时点的优惠价，官方另有「5 折长期有效」措辞（`UNK-17`）；免费层条款随时可变。

## 0. 先判定要不要后端

**一句话结论**：先判断数据要不要离开用户设备。纯单机、零网络请求的项目，月固定成本可以是 0 元；19.9 元/月只在「需要后端」这一支出现。【官网明确】+【推算】

### 这张表回答什么

我的项目是不是必须有一个后端？八个维度任一命中，就离开 0 元档。

| 维度 | 命中条件 | 为什么客户端做不了 | 平台代做能否覆盖 | 证据性质 |
|---|---|---|---|---|
| 跨设备 / 自有账号 | 换手机要接着玩 | 本地数据按用户与设备隔离 | 平台托管数据可部分覆盖 | 【官网明确】 |
| 权威防作弊排行榜 | 成绩要可信、要全服 | 客户端上报分数可篡改 | 好友榜可覆盖，全服榜不行 | 【官网明确】 |
| 虚拟支付 | 卖道具或订阅 | 需企业主体 + 发货回调 + 幂等 | 否 | 【官网明确】 |
| 广告服务端奖励验证 | 奖励发放要防刷 | 回调地址需可备案域名 | 可选开关，不强制 | 【官网明确】 |
| UGC 内容过滤 | 用户能发内容 | 需要内容安全检测与存储 | 平台能力有限 | 【官网明确】 |
| 远程配置 / Kill Switch / 埋点 | 不发版改配置、看数据 | 代码包不能热更 | 部分平台提供 | 【官网明确】 |
| 大资源超包体 | 素材放不进代码包 | 超限需 `downloadFile` | 否，反触发域名备案 | 【官网明确】 |
| 联机对战 | 房间、匹配、帧同步 | 需权威服务器 | 否 | 【官网明确】 |

**怎么读**：先看「平台代做能否覆盖」——「需要后端」≠「必须自建服务器」，但「平台代做」≠「豁免合规」。八维详见 [代价对照](../decisions/不选与选用serverless的代价.md) §5。

## 1. 19.9 的重新定义与打平口径

### 1.1 平台范围与一个出局说明

本册面向个人制作者，覆盖微信、TapTap、抖音、支付宝、快手、QQ 与境外纯 Web 方案。**华为云 FunctionGraph 不纳入**：其 HTTP 函数没有独立公网端点、共享版网关已退市、专享版实例费是千元级最小计费单元，讨论它会把「先判定要不要后端」拉回「先买一台服务器」的旧框架；该结论的完整依据见 [代价对照](../decisions/不选与选用serverless的代价.md) §1.2。【官网明确】

其余涉及该厂商之处一律用「HW 云」代称 + `HW-` 来源编号。

### 1.2 19.9 是什么

19.9 元/月是微信云开发基础套餐（腾讯云 CloudBase 个人版）的优惠价，官方另写原价 39 元/月；「限时优惠」与「5 折长期有效」两处措辞并存，见 `UNK-17`、`UNK-18`。它买到的是 **40,000 资源点/月**（1000 点 = 1 元）与一整套 BaaS 能力，不是一台机器，也不是所有项目的入场费。【官网明确】

正确口径：**数据需要离开设备之后的最低后端价**。

### 1.3 四类打平口径（全收但分层）

| 类别 | 代表项 | 触发离开 0 元的条件 | 证据性质 |
|---|---|---|---|
| 长期 0 元 | 纯单机本地存储、平台代做能力、境外纯 Web 免费层 | 无 | 【官网明确】 |
| 有条件 0 元 | 微信免费云环境、AI 成长计划、TapTap 薪火计划、兑换码体验版 | 活动截止日、上线后到期、需续期 | 【官网明确】 |
| ≈19.9 付费 | 云开发个人版、低价轻量 VM 自建 | 需要后端且要可持续 | 【官网明确·取样时点】 |
| 免费能力清单 | TapTap 云存档、数据存储、文件、排行榜 | 需要云引擎实例时开始计费 | 【官网明确】 |

数值一律按 `S-060`~`S-079` 回查 [价格快照](../_shared/价格快照-2026-11.md)，本页不抄第二份。

### 1.4 双轴分叉

轴一：小游戏 / 小程序·工具类；轴二：无广告纯单机 → 平台广告 IAA → 内购 IAP。每升一档，新增成本与资质要求见 §2.6 与 §3.6。境外 0 元方案只对「纯 Web / 工具类」成立：**境内主体小程序的 `request` 合法域名必须 ICP 备案，境外注册域名无法备案**，故境外 0 元后端不能承载境内主体小程序。【官网明确】

## 2. 小游戏线

### 2.1 TapTap 单机多不多

**定性成立，无占比数字**。「单机」是官方正式标签（定义：不含持续运营、排行榜等要素），有官方单机休闲合辑与休闲榜单机条目；首期官方征集只收轻量无内购作品；官方云存档文案直接写「解决单机游戏痛点」。【官网明确】

TapTap 从未公布小游戏总数、分类分布、单机占比，两期征集最终名单亦未公示，见 `UNK-01`。媒体转述的「上半年 5002 款新游、4000+ AI 生成小游戏」是全站含 APK 口径，只作第三方线索，**本册不写百分比**。【开发者自述】

### 2.2 2026-11-04 创意工坊三档

| 档位 | 前置 | 时限 | 是否需后端 | 证据性质 |
|---|---|---|---|---|
| 单机·无广告 | 无需升级申请，平台自动升级为独立游戏 | — | 否 | 【官网明确】 |
| 单机·有广告 | 只需小游戏备案 | 约 1 工作日 | 否 | 【官网明确】 |
| 联网·有广告 | 备案 + ICP 核准 | 约 21 工作日 | 视能力而定 | 【官网明确】 |

官方解读另提示：带排行榜、云存档这类服务端能力时，建议先按联网确认（`TT-` 来源编号见 [来源清单](../appendix/来源清单.md)）。【官网明确】

### 2.3 纯单机 0 元上架成立链

上架必接能力只有「添加到桌面」；云存档、离线游玩、登录、排行榜、多人联机全是**可选**能力。云存档完全免费（单玩家单游戏 100 个存档 / 100 MB、单文件 10 MB）。防沉迷在「游玩方式仅有小游戏」时默认依托平台开启，开发者无需额外操作。广告变现零分成且个人主体可接，官方文档未列强制服务端回调。H5 小游戏支持纯静态构建产物。前置备案是一站式流程，整合了 ICP 核准，个人主体可用「游戏内容介绍说明」替代版号，约 20 工作日，未见收费项。【官网明确】

### 2.4 边界与坑

- 「主题创作征集 #2 强制接云存档」是**评奖资格**，不是上架条件；活动问答明确允许未符合者先投稿后完善。【官网明确】
- 「完全断网启动」不是默认能力，需离线模式白名单并联系商务开通 OSS，非自助。【官网明确】
- 包体口径存在多个官方数值，见 `UNK-04`、`UNK-15`；设计按首包尽量小，不按活动上限。
- 软著需「原始取得」的登记证书；两处官方口径是否必需不一致，见 `UNK-11`。
- 上架流程与 42 条锚点见 [纯单机上线全流程](../flows/纯单机上线全流程.md) §4。

### 2.5 微信小游戏纯单机

零网络请求时不触发服务器域名配置；官方社区置顶帖中「可以不配置服务器域名、审核不管后台怎么设置」的回复者是第三方开发者「微喵网络」，标 `【开发者自述】` 并挂 `UNK-09`。**微信侧拿不到官方专员明文说「无后端可上架」**，最硬的官方证据是：备案材料清单无服务器/域名/云资源、工信部《备案登记表》注明小程序与快应用无需填写域名列表和网络接入信息、审核规范 3.1.5 只管功能是否有使用价值。【官网明确】+【开发者自述】

微信小游戏**没有**「单机」专门分类、标签或专项扶持，官方按 IAP / IAA 分备案通道。【官网明确】

### 2.7 抖音小游戏（新增）

个人主体可申请，但 **0 元纯单机高度存疑**：软著是必须项且作品备案须国家版权局纸质登记证书（电子软著不能用于备案）、必须作品备案与自审自查、棋牌类禁入；最关键的是**防沉迷实名法律责任由开发者自行承担**，与微信「平台统一代做」完全不同。【官网明确】

抖音云文档库与配置中心「当前暂未收费、限频 200QPS」是现状而非承诺；日志分区有每服务月度最低消费；首次开通有限期体验代金券，属限期活动不进免费层主表；2024-06-22 起已取消试用资源包，云函数需定向邀测。数值按 `S-160`~`S-169` 回查。【官网明确】

「15 天免费冷启」需修正：15 天是数据评级起始日，免费冷启为「上线 30 天内申请、申请后 7 天内下发 5k–1w 曝光」。任务金与投放金有活动截止日，不写成长期权益。【官网明确】

冲突登记：个人小游戏数量 `UNK-32`、「不接后端可上架」无近期官方重述 `UNK-33`、长期额度与个人 IAP `UNK-28`/`UNK-29`。

## 3. 小程序 / 工具类线

### 3.1 与小游戏的分界

类目一经选定不可变更；游戏类目有备案前置审批，工具类没有；IAP 通道对个人主体不开放。三条线各自独立，不能混用资质材料。【官网明确】

### 3.2 微信工具类纯单机 0 元

小程序备案（APP 备案）2023-09 起所有小程序上架前必做，平台以 `errcode 86369` 硬校验，但**免费**，个人必需材料仅有效身份证件、人脸核身、12381 短信核验（24h 内）与承诺书，清单中**没有服务器、域名或云资源**。域名 ICP 备案是另一层，纯单机零网络请求不构成备案对象。【官网明确】

本地存储与包体硬约束按 `S-001`~`S-019`、`S-100`~`S-119` 回查；超限改用 `downloadFile` 会反向触发域名备案。清缓存或卸载会清掉本地数据。【官网明确】

### 3.3 最常见的驳回不是「没有后端」

审核规范 3.1.5 要求「功能应具有使用价值，不能过于简单」，并要求简介与实际功能一致；驳回多因内容像测试版，而非缺少服务端。【官网明确】

### 3.4 支付宝小程序

个人实名账号可创建小程序，备案免费；但支付宝**小游戏**明确「个人账号暂不支持创建」。工具类 0 元成立。【官网明确】

### 3.5 境外纯 Web / 工具类线

Cloudflare Workers、Neon、Deno Deploy、EdgeOne 免费版、七牛云等提供长期 0 元层，但**不能承载境内主体小程序的 `request` 合法域名**（境外域名无法备案）。它们适用于纯 Web、出海或非微信场景。额度按 `S-120`~`S-139` 回查。【官网明确】

### 3.6 变现三档成本递增（工具类）

| 档位 | 新增成本 | 是否需后端 | 证据性质 |
|---|---|---|---|
| 无后端纯工具 | 0 元，备案与审核 | 否 | 【官网明确】 |
| 平台广告 | 流量主门槛、广告联网 | 通常否 | 【官网明确】 |
| 内购或订阅 | 企业/个体户主体 + 支付通道 | 是 | 【官网明确】 |

### 3.7 抖音小程序（新增）

个人主体可注册（身份证、满 18、实名认证、数量上限、主体类型认证后不可变更），**ICP 备案强制**，类目限《个人主体开放服务类目》，工具类可直接申请，图片/音视频/AI 等定向准入。**个人不支持任何虚拟支付或交易**，只能广告变现。纯单机零网络请求可不配服务器域名，但只有 2022 年管理员回复与《网络》文档的「跳过域名校验」，无 2025–2026 官方重述，挂 `UNK-33`。【官网明确】+【未查到·不确定】

流量主门槛两种官方数值并存，见 `UNK-31`。审核高频驳回：无实质服务内容、空白页、UGC 未接内容安全检测、站外引流。【官网明确】

## 4. 合规三层彻底分清

| 层 | 备案对象 | 是否需服务器 | 是否需企业 | 费用 | 证据性质 |
|---|---|---|---|---|---|
| 小程序备案（APP 备案） | 应用与主办者 | 否 | 否 | 免费 | 【官网明确】 |
| 域名 ICP 备案 | 域名与接入资源 | 是 | 否 | 免费但需云资源 | 【官网明确】 |
| 版号 / 游戏前置审批 | 出版物 | — | 是 | — | 【官网明确】 |

补充口径：HW 云《准备可备案的服务器》表 1 只列 ECS、Flexus X/L、企业门户、专属云、公网 NAT 网关，**未列**函数工作流、API 网关、对象存储，也无 Serverless 资源包——只能写「清单未列」，不能写「不可备案」，见 `UNK-27`。腾讯云 SCF 购买调用与资源用量包可备案 2 个服务，阿里云函数计算购买 CU 资源包可获备案服务码；备案本身不收费，但需要满足包月时长或资源包条件。【官网明确】

备案口径张力：内蒙古管局答复「单机不联网的 APP、小程序无需备案」，而微信平台发布环节硬校验备案号。本册按「必须备案（免费）」操作，**不押注豁免**。【官网明确】+【未查到·不确定】

防沉迷强制且**单机不豁免**；微信由健康系统统一代做、开发者零接入，抖音法律责任由开发者自担。「平台代做」不等于「豁免」，见 `UNK-06`。软著官费 0 元（2017 起停征），代理与加急才收费；两处官方文档口径不一致，见 `UNK-11`。TapTap 所有游戏需隐私协议，不因不联网而省。【官网明确】

### 5.2 隐性后端触发器与平台代做

八维触发器的逐条展开见 [代价对照](../decisions/不选与选用serverless的代价.md) §5。结论：**「需要后端」≠「必须自建服务器」**；微信开放数据域好友榜、TapTap 免费云存档与排行榜、抖音排行榜都由平台承担，但它们各自有额度与语义限制，且不能替代合规义务。

从 0 元档跳到 19.9 档的典型升级路径：跨设备同步 → 自有账号 → 权威榜 → 支付。每一步的不可逆点见 [代价对照](../decisions/不选与选用serverless的代价.md) §5 与 `S-080`~`S-099`。

## 6. 八个坑

| # | 错在哪 | 正确口径 | 依据 |
|---|---|---|---|
| 1 | 纯单机 = 不用备案 | 小程序备案仍要做，只是免费且不需服务器 | §4、`WX-` 组 |
| 2 | 备案需买服务器 | 那说的是域名 ICP 备案，两层不能混 | §4、`HW-` 组 |
| 3 | 0 元 = 0 成本 | 时间、材料、能力限制、数据易失都是成本 | §0 |
| 4 | 无内购纯广告 = 法律免版号 | 是平台审核口径，非法律豁免 | `UNK-02`/`UNK-10` |
| 5 | 不联网就不用隐私政策与防沉迷 | TapTap 强制隐私协议，防沉迷单机不豁免 | §4、`UNK-06` |
| 6 | 把社区置顶帖当官方公告 | 该回复者是第三方开发者 | `UNK-09` |
| 7 | 把 IAA 代备案写成免版号 | 官方只有「代备案授权书」 | `UNK-02`/`UNK-10` |
| 8 | 把抖音当微信 | 软著、备案、防沉迷责任、支付口径都不同 | §2.7 / §3.7 |

## 7. 结论与决策卡

**一句话**：先判定要不要后端；纯单机分支月固定成本 0 元，19.9 是「需要后端」分支的最低起步价。

| 你的情况 | 建议动作 | 去哪查 |
|---|---|---|
| 数据只在设备、不做榜与支付 | 走纯单机 0 元 | `flows/` §2~§4 |
| 需要跨设备或好友榜 | 先查平台代做能力，再决定是否买套餐 | §5.2、`decisions/` |
| 需要内购或权威全服榜 | 接受企业主体、版号与后端成本 | §2.6、`decisions/` |
| 做纯 Web / 工具类 | 境外 0 元层可用，但境内主体小程序不适用 | §3.5 |

复核提示：按 `appendix/来源清单.md` 的 URL 自查并记录日期；19.9 与免费层条款随时可变；`UNK-01`~`UNK-36` 的冲突项只登记未裁决，实际操作按平台后台实时提示。术语定义统一查 [术语表](../appendix/术语表.md)。
