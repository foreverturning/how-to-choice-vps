# 03 查验命令与灰色手法识别表

> **用途**：买前验机、买后复核、看到低价报价时快速对照。
> **用法**：先跑第 1 节 30 秒快筛，再按第 2 节五组深查，最后用第 3 节对照销售话术。
> **上游**：[三档成本模型](../_shared/三档成本模型.md)｜**对应**：[05 成本解剖篇 5.5](../chapters/05-成本解剖篇.md#55-灰色节省清单)、[07 低价机篇 7.6](../chapters/07-低价机篇.md)、[Lab 6 低价 VPS 体检](../labs/Lab6-低价VPS体检.md)

**做完你会得到什么**：一张可打印的验机记录表、一张能贴墙的灰色手法对照表，以及一套“先排除、再深查”的判断顺序。

---

## 0. 使用前提

1. **只在自己的机器或已获书面授权的机器上执行**。扫描、压测他人地址既无意义也有法律风险。
2. 标 `sudo` 的命令需要 root；`smartctl`、`nvme`、`dmidecode` 在部分虚拟机上不可用，返回“命令不存在”本身就是信息（多半是 OpenVZ/LXC 或权限被收走）。
3. 测速与 `fio` 会消耗流量和磁盘 IO。生产环境避开业务高峰，测试文件用完即删。
4. **同一项至少测两次**：晚高峰（20:00–23:00）一次、凌晨一次。单次跑分不能定性，差异才能定性。
5. 判读阈值与 `_shared` 保持一致：`st` 长期 >5%、通电 >3 万小时、`percentage_used` >20%、4K 随机写 <500 IOPS、晚高峰速率 <标称 50%、丢包 >5%、IP 信誉分 >25。

## 1. 30 秒快筛表

这张表回答一个问题：**有没有必要继续测下去**。五个动作，任一条命中红灯就先别付款。

| # | 动作 | 命令 | 30 秒看什么 | 命中即红 |
|---|---|---|---|---|
| 1 | 出口 IP vs 网卡地址 | `curl -4 -s https://ifconfig.me` 与 `ip -4 addr` | 网卡上是 `10.x` / `172.16.x` / `100.64.x`，出口却是公网 | 典型 NAT，不是独立 IP |
| 2 | 虚拟化类型 | `systemd-detect-virt` | 返回 `openvz`、`lxc` | 共享内核，内存与内核参数不可控，跑分失真 |
| 3 | CPU 被邻居偷走多少 | `mpstat -P ALL 1 5` | `%steal` 持续 >5%，晚高峰 >20% | 重度超售 |
| 4 | 内存与磁盘是否缩水 | `free -h` 与 `df -h` | `available` 明显小于标称；根分区小于套餐 | 虚标配置或系统盘被切走 |
| 5 | 线路与丢包 | `mtr -rwzc 50 <目标IP>` 或 `ping -c 50 <目标IP>` | 某一跳起持续丢包 >5%，晚高峰速率 <标称 50% | 共享带宽 / 假线路 |

**读法**：5 条里中 2 条以上，直接放弃年付；只中 1 条，进入第 2 节对应分组深查。快筛只做排除，不做背书——全绿也不等于没有隐性限速。

## 2. 查验命令清单（五组）

### 2.1 硬件组：它到底是不是它宣称的那台机器

| 目的 | 命令 | 判读标准 |
|---|---|---|
| 看 CPU 型号、代数、核心数 | `lscpu` | 型号与套餐一致；老至强（如 E5 v2/v3）说明是折旧期满硬件；`CPU(s)` 与售卖核数对得上 |
| 看真实内存与 Swap | `free -h` | `available` 接近标称；Swap 被大量占用说明靠交换撑内存；低价机常见 2G 标称、1.2G 可用 |
| 看磁盘是 SSD 还是机械盘 | `lsblk -d -o NAME,ROTA,MODEL,SIZE` | `ROTA=1` 是机械盘；`MODEL` 为陌生杂牌或与宣传不符要警惕；容量与套餐一致 |
| 看 SATA/SAS 盘健康 | `sudo smartctl -a /dev/sda` | `Power_On_Hours` >3 万小时为二手；`Reallocated_Sector_Ct` 非 0、`Pending_Sector` 非 0 直接扣分 |
| 看 NVMe 寿命 | `sudo nvme smart-log /dev/nvme0` | `percentage_used` >20% 接近寿命尾声；`media_errors` 非 0 说明已出错 |
| 看虚拟化类型 | `systemd-detect-virt` | `kvm` 为正常独立内核；`openvz` / `lxc` 共享内核，内存与 IO 不可信 |
| 看分区与剩余空间 | `df -h` | 根分区大小与套餐一致；`Use%` 异常高可能是模板遗留；`/` 是网络盘时 IO 会抖 |

### 2.2 性能组：超售与限速藏在这里

| 目的 | 命令 | 判读标准 |
|---|---|---|
| 测 CPU 基线算力 | `sysbench cpu --threads=2 --time=30 run` | 同型号独服应有稳定 events/s；比公开基线低 30% 以上，或两次差异 >20%，视为被争抢 |
| 测内存带宽 | `sysbench memory --memory-block-size=1M --memory-total-size=2G run` | 数值明显低于同代平台，且晚高峰下降，说明内存带宽被邻居分走 |
| 测 4K 随机读写 | `fio --name=rw --rw=randrw --bs=4k --size=512M --numjobs=4 --runtime=30 --time_based --group_reporting` | 随机写 <500 IOPS 视为机械盘或严重限速；IOPS 抖动 >30% 说明共享存储 |
| 测顺序读上限 | `fio --name=seq --rw=read --bs=1M --size=1G --numjobs=1 --runtime=30 --time_based --group_reporting` | 远低于 100 MB/s 基本不是本地 SSD；接近标称才说明没被限速 |
| 看 CPU steal 与负载 | `mpstat -P ALL 1 5` | `%steal` 长期 >5%、晚高峰 >20% 为超售；`%iowait` 长期偏高说明磁盘是瓶颈 |

> ⚠️ `fio` 会写文件，先 `cd` 到临时目录，测完删除；不要在系统盘写满。

### 2.3 网络组：标称带宽只是峰值

| 目的 | 命令 | 判读标准 |
|---|---|---|
| 测实际吞吐 | `iperf3 -c <对端IP> -t 60 -P 8` | 多线程仍达不到标称 50%，是共享带宽；能跑满但单线程很低，是单流限速 |
| 看逐跳丢包 | `mtr -rwzc 50 <目标IP>` | 丢包从某一跳开始且持续到终点，问题在该段；全程零星丢包看是否为本地网络 |
| 看回程路由 | `traceroute -T -p 443 <目标IP>` | 宣称 CN2 的线路应全程 `59.43.x.x` / AS4809；出现 `202.97` 多为 163 骨干，不是 CN2 GIA |
| 看延迟稳定性 | `ping -c 50 <目标IP>` | 平均延迟正常但 `mdev` 大、尾部丢包，说明晚高峰拥塞；连续 10 分钟采样更能说明问题 |
| 测单线程下载 | `curl -s -o /dev/null -w "%{speed_download}\n" https://speed.cloudflare.com/__down?bytes=100000000` | 输出为 B/s，乘 8 除 1e6 得 Mbps；与 `iperf3` 结果差距过大，说明多线程被特殊对待 |

### 2.4 IP 组：独立、共享还是 NAT

| 目的 | 命令 | 判读标准 |
|---|---|---|
| 看出口 IP | `curl -4 -s https://ifconfig.me` | 记录返回值与查询时间；重启前后各测一次，变化即动态 IP |
| 看网卡真实地址 | `ip -4 addr` | 只有内网地址而出口是公网，就是 NAT；有公网地址还需确认是否 1:1 映射 |
| 看 IP 归属 | `whois <你的IP>` | `netname`、`country`、`org` 与宣传地区一致；归属为住宅宽带或不明组织，不是机房 IP |
| 看端口是否真开放 | `nc -vz <你的IP> 443` | 从外部机器执行；面板显示开放但外部不通，说明还有一层 NAT 或防火墙 |
| 看重启后是否换 IP | 重启后重跑 `curl -4 -s https://ifconfig.me` | 两次不同即动态 IP；所谓“固定 IP”必须写进合同才算 |

### 2.5 合规组：查得到才叫有

这一组不教任何绕过方法，只查“对方有没有资格提供服务”。

| 目的 | 入口 / 命令 | 要查的字段 |
|---|---|---|
| 查 IDC/ISP 许可证 | `https://dxzhgl.miit.gov.cn` → 许可信息查询 → 输入企业全称 | 企业名称、许可证编号、业务种类（IDC/ISP）、覆盖范围、有效期 |
| 查 ICP 备案 | `https://beian.miit.gov.cn` → 公共查询 → 输入域名 | 主办单位、备案号、网站域名、审核日期；主体与销售方是否一致 |
| 查经营主体 | 国家企业信用信息公示系统，输入公司全称 | 成立日期、注册资本、经营状态、是否有行政处罚 |
| 查域名注册信息 | `whois <你的域名>` | 注册商、创建时间、到期时间；刚注册的域名做“长期套餐”要警惕 |
| 查发票与合同 | 人工索要 | 能否开票、发票类型、合同是否写“最低保证带宽”“SLA 赔付”“退款条款” |

**合规组的三条底线**：查不到许可证，就不能合规提供机房托管与公网接入；查不到备案主体，国内网站随时可能被拦截；只收预付款、不签合同、不开发票，维权时没有抓手。

## 3. 灰色手法识别表（一页纸贴墙版）

这张表回答：**这个低价是从哪省出来的，代价落到谁头上**。左列是手法，右列是你能当场验证的动作。

| 灰色手法 | 省下的成本 | 用户代价 | 识别方法 | 一句话结论 |
|---|---|---|---|---|
| 共享带宽超售 1:5–1:20 | 带宽成本降 50%–90% | 晚高峰只剩标称 10%–50% | 晚高峰与凌晨各跑一次 `iperf3`，对比同一目标 | 标称是峰值，不是保证值 |
| “独享端口”冒充“独享带宽” | 独享带宽成本降 50%+ | 和邻居抢同一条 uplink | 问合同是否写“最低保证带宽”，不写就是没有 | 端口独享 ≠ 带宽独享 |
| 假 BGP（单线 + BGP 广播） | 多线成本降 30%–60% | 某一运营商访问明显慢 | 三网分别 `mtr`；`bgp.he.net` 查 AS 与前缀 | 有 ASN 不等于多线接入 |
| 假 CN2（202.97 冒充 59.43） | 优质线路成本降 50%+ | 晚高峰丢包、绕路 | `traceroute` 看回程是否全程 `59.43`/AS4809 | 一段 59.43 不算 CN2 |
| 假高防（1G 口称 8G 防御） | 清洗带宽成本降 80%+ | 一打就死，业务中断 | 问清洗带宽、牵引方式、是否单独计费 | 防御值是宣传，清洗带宽才是能力 |
| NAT / 共享 IP 冒充独立 IP | IP 成本降 50%–90% | 端口受限、被封时被牵连 | `curl -4 -s https://ifconfig.me` 对比 `ip -4 addr`；外部 `nc -vz` 常用端口 | 网卡是内网地址就是 NAT |
| 动态 IP 伪装固定 IP | IP 管理成本降 | 重启换 IP、白名单失效 | 记录重启前后出口 IP；看是否有 DHCP 租约 | 没写进合同的“固定”都不算 |
| 二手盘翻新 | 存储成本降 50%–80% | 掉盘、IO 抖动、数据丢失 | `smartctl` 看通电时长与重映射；`nvme smart-log` 看寿命 | 通电 3 万小时以上按二手算 |
| “不限量”达量限速 | 带宽成本可控 | 超量后降到 1Mbps | 读“公平使用/达量限速”条款；跑满月流量后再测 | 不限量 ≠ 不限速 |
| 所谓“永久/终身”套餐预付款 | 提前锁定现金流 | 商家消失、数据丢失 | 查主体成立年限、付款方式、有无月付选项 | 预付款是风险敞口，不是折扣 |
| 内存 balloon / Swap 充内存 | 内存成本降 30%–60% | 高负载 OOM、卡顿 | `free -h` 看 `available` 与 Swap；对比标称配置 | 标称 2G、可用 1.2G 就是缩水 |
| 家宽 / 民房机房 | 机柜电力成本降 80%+ | 无 UPS、无消防、随时断网 | 问机房地址与 Tier 等级；`whois` 看归属 | 机房不在 IDC 列表里就是风险 |
| 无证 IDC / 无备案 / 无发票 | 合规成本降 30%–50% | 随时被关停、无法维权 | `dxzhgl.miit.gov.cn` 查许可证；`beian.miit.gov.cn` 查备案 | 查不到证 = 不受监管 |
| 黑 IP / 被墙 IP / 二手 IP | IP 成本降 50%+ | 邮件进垃圾箱、站点打不开 | `abuseipdb` 看信誉分；`whois` 看归属与历史 | 干净 IP 要花钱，便宜 IP 有历史 |
| 盗版 Windows / 面板 / 软件 | 许可成本归零 | 后门风险、法律风险 | 问授权来源与凭证，看是否有正版证明 | 无凭证即无授权 |

**读法**：销售每强调一个卖点，就在表里找对应行。找得到验证动作，才算真卖点；找不到，就按“未证实”处理。

### 3.1 三条判读原则

1. **物理不成立**：150 台 VM 各 5M 独享就是 750M 出口，按较低的灰色带宽 24 元/M 算也要 18,000 元/月，折 120 元/VM/月。卖几十元一年，承诺本身就不成立。
2. **合同不写等于没有**：广告里的“独享”“不限量”“高防”都不算数，只有合同里的“最低保证带宽”“清洗带宽”“SLA 赔付”才算。
3. **组合成本有下限**：独立 IPv4 租用约 3.0–4.3 元/月（快照 P-027，2026-11），一年 36–52 元，已接近 C 档 36 元/年的整机地板。卖 30 元/年还宣称“独立 IP”，必然在别处省：NAT、超售、限速或跑路，至少中一项。

## 4. 验机记录表（模板，含示例行）

这张表回答：**测完怎么留证据**。同一台机器至少记录两轮（晚高峰 / 凌晨），结论才站得住。

| 组 | 项目 | 命令 | 实测值 | 判读 | 结论 |
|---|---|---|---|---|---|
| 硬件 | 硬盘通电时长 | `sudo smartctl -a /dev/sda` | `Power_On_Hours 41200` | >3 万小时，二手盘 | 资源真实性扣分 |
| 硬件 | 虚拟化 | `systemd-detect-virt` | `kvm` | 独立内核 | 通过 |
| 性能 | CPU steal | `mpstat -P ALL 1 5` | 晚高峰 `%steal 18%` | >5%，邻居争抢 | 疑似超售 |
| 网络 | 晚高峰吞吐 | `iperf3 -c <对端IP> -t 60 -P 8` | 标称 5M，实测 2.1M | <50% 标称 | 共享带宽 |
| IP | 出口一致性 | `curl -4 -s https://ifconfig.me` | 与面板一致，公网地址 | 非 NAT | 通过 |
| 合规 | 许可证 | `https://dxzhgl.miit.gov.cn` | 查无记录 | 无 IDC/ISP 证 | 不建议年付 |

**怎么填**：一行只放一个判断；“实测值”写原始数字和时间，不写“很快”“还行”；“结论”只写通过 / 扣分 / 否决三档。示例行是示意，不是实测结果，替换成你自己的输出。
