## 任务卡

### S1 写作规范

- 统一语气、章节模板、表格/代码块规范、交叉引用格式
- 价格标注规则（快照 / 自核 / 待核对）
- 禁用词：具体商家名、绝对化承诺、“永久”
- 免责声明模板
- 每篇交付物与自查清单

### S2 价格快照-2026-11

- `data-version: 2026-11-08.1`（数据层，唯一价格源；变更登记见 `ops/数据变更记录.md`）
- 字段：厂商类型 / 配置 / 首年 / 续费 / 带宽 / 流量 / IP 类型 / 备注 / 核对日期
- 覆盖：国内大厂、中小 IDC、海外 VPS、免费 PaaS
- 每条给编号 `P-001…`，来源与日期
- 不点名商家；用类型化描述
- 汇率：1 USD ≈ 7.2 CNY

### S3 三档成本模型

- `data-version: 2026-11-08.1`（数据层，依赖 S2 @ 同版本；变更登记见 `ops/数据变更记录.md`）
- A 合规大厂 / B 中小 IDC / C 灰色超售
- 单 VM 月成本表（与总纲 5.6 一致）
- 三张饼图数据口径（注明区间型不做精确加总）
- 评分卡六维权重 + 三色灯阈值
- 查验命令清单
- 成本地板计算公式

### C01–C08 章节

- 严格按总纲对应小节，不增删一级小节
- 每节先结论后论证；多用表格/清单
- 引用快照编号；自核数据单独成表
- 文末：本篇交付物、配套 Lab 链接、免责声明
- 06/07 必须与 C05 的三档表和阈值一致

### L1–L6

- 统一结构：目标 → 前置条件 → 步骤 → 命令 → 产出 → 常见问题 → 安全提示
- 命令可复制；涉及费用的步骤标注“可能产生费用”
- 不要求真实执行，但步骤必须自洽

### T01–T05

- 模板类文件要给“怎么填”的示例行
- 与 `_shared` 的数字、术语保持一致
- 能用表格就不用长段落

### A01 附录

- A 价格快照索引 / B 成本计算过程 / C 查验命令 / D 工信部查询步骤 / E 术语索引 / F 参考资料
- 只做汇编与索引，不引入新数字

### Q1–Q3

- 只读正文，问题写进 `qa/p7-*.md`
- 检查：数字一致性、商家名、免责声明、交叉链接、字数、术语
- 每条问题给“文件 + 章节 + 问题 + 建议修法”
