## 0. 定位与时效性免责

- 本表是 2026-11-12 时点对厂商公开免费层条款的取样，不是报价单，也不替代章节结论。

## 1. 「0 成本部署」的边界

**算**：厂商公示的长期免费层内、0 元即可开通并保持的调用量、资源额度与存储额度（次、GB-s、GB、请求数等），以及附带的期限与重置规则。

**不算**（本节只定性、不给数字）：预置并发与常驻实例的闲置占用、公网出流量、日志与监控存储、API 网关、独立公网 IP、配套对象存储与数据库、自定义域名与证书、以及超出免费层之后的任何用量。

**四种期限形态**（沿用本分册写作规范）：

| 形态 | 含义 | 是否进主表 |
|---|---|---|
| 长期每月重置 | 每自然月月初清零、不累积 | 进 |
| 前 N 个月试用 / 需领取 | 有明确结束时间，需主动领取 | 不进，作注脚 |
| 需手动续期 | 到期不续即停服释放 | 不进，作注脚 |
| 限期代金券 / 活动价 | 有有效期或截止日 | 不进，作注脚 |

> **筛选器对账**：本表把「不进」的期限形态排除在主表外，属于取样口径，不表示这类方案不存在（C3）。每次使用本筛选器，须在 `appendix/覆盖面候选集.md §3` 回写「本次排除的类别 + 是否另有独立核查 + 在哪」；被排除类别未另查时登记 `UNK-` 或 `RQ-`。

**本次实际对账（DC-003，2026-11-14）**：四种期限形态中「需手动续期 / 前 N 个月试用 / 限期活动」三类被排除在主表外，共涉及 uniCloud 免费服务空间、腾讯云 CloudBase 免费体验版、Bmob 免费版、阿里云 FC 新用户试用额度、百度智能云 CFC 0 元新客包五类项目；**是否另有独立核查 = 是**，逐项见本文件 §7 与 `appendix/覆盖面候选集.md §1/§3`。被排除类别不再以「不进主表」为由从候选集消失；官网未取到明文的另登记 `UNK-53`/`UNK-55`/`UNK-58`。

**开通门槛**：实名、绑卡、备案、需领取、需手动续期，记为「门槛」，不视为破坏 0 成本；但一旦触发自动转按量，就离开 0 成本。

## 4. 超量触发语义（三类标签）

| 标签 | 含义 |
|---|---|
| 停服 / 限流 | 超限即不可用或降级，不自动产生费用；可用性掉，账单不动 |
| 需手动开启超限不停服 | 默认不超额，主动开启后超出部分按量结算 |
| 异常滥用自动转付费 / 封禁 | 识别到爬虫、挖矿等异常，自动转付费环境或直接封禁 |

**读法**：先看「期限类型」判断是不是长期，再看「重置/清零」判断能不能攒，最后用三类标签判断超限那一刻会发生什么。注意「免费体验版暂不支持开启按量付费」与「付费套餐超限默认限制使用」是两条不同条款，不可混写（`UNK-08`）。
