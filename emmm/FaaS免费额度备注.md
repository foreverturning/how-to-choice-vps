## 0. 定位与时效性免责

- 本表是 **2026-11-10 时点**对厂商公开免费层条款的取样，不是报价单，也不是教学目标的事实源。
- 免费层条款**随时可变、可能缩减或整体取消**；历史上已有厂商取消每月免费额度，老用户不再享受。
- 一切以官网当期条款为准（厂商官网定价页 / 官方帮助中心），使用前请逐条复核「期限或重置」与「超限后」两列。
- 本表**不做推荐、不做横向比较、不构成购买建议**；点名仅用于标记「哪家有 0 元免费层」，限于公开定价/免费额度页的出处记录。
- 表内数字只涉及 **0 成本部署**（金额恒为 0 的免费额度），不含任何付费单价、套餐价或折算金额。

## 1. 「0 成本部署」的边界

**算**：厂商公示的 FaaS 函数免费层内、0 元即可开通并保持的调用量与资源额度（次、GB-s、CU、资源点、请求数等），以及该免费层附带的期限与重置规则。

**不算**（本节只定性、不给数字）：预置并发与常驻实例的闲置占用、公网出流量、日志与监控存储、API 网关、独立公网 IP / EIP、配套对象存储与数据库、自定义域名与证书、以及超出免费层之后的任何用量。

**开通门槛**：实名、绑卡、备案、需领取、需手动续期，记为「门槛」，不视为破坏 0 成本；但一旦「自动转按量」被触发，就**离开 0 成本**，归入第 3 节第三类标签。

**期限退出的真实案例**：百度智能云 CFC 自 2023-03-10 起取消每月免费额度，改走「0 元新客包」且仅连续 3 个月。它已不是长期 0 元免费层，**不进主表**，只作为「看起来永久、实际会收回」的注脚。

## 3. 其他部分：类型化，不写数字

**超量触发语义**只有三类标签，用来回答「额度用完会不会突然扣钱」：

| 标签 | 含义 |
|---|---|
| 停服 / 限流 | 超限即不可用或降级，不自动产生费用；可用性掉，但账单不动 |
| 需手动开启超限不停服 | 默认不超额；只有用户主动开启后，超出部分才在次日按量结算 |
| 自动转按量 | 超限即产生费用 → **立刻离开 0 成本部署** |

**门槛与坑点（定性）**：冷启动、单次执行时长上限、并发上限、禁止商用、闲置回收、需领取、需实名或绑卡、到期不续即释放、条款可调、免费额度是否覆盖出网流量与日志、预置并发是否另行计费、免费额度是否可跨月累积、国内站与国际站口径是否一致。

**读法**：先看「期限类型」判断它是不是真的长期，再看「重置 / 清零方式」判断能不能攒，最后用上面的三类标签判断超限那一刻会发生什么。这与 `chapters/03-白嫖篇.md` 3.5 的「到期日历」和 3.6 的「自动转按量」是同一套检查动作。
