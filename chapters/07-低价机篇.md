# 07 低价机专题：几十元“固定 IPv4”深度拆解

> 一句话结论：几十元一年的“固定 IPv4”不是骗局就是补贴，能不能买取决于你把它放在哪一档用途上。
> 读完你能：识别 5 种低价机来源 / 分清“固定 IP”的 4 种真相 / 用 8 步验机 / 判断它适不适合你。
> 对应总纲：7.1–7.8 ｜ 配套 Lab：[Lab 6 低价 VPS 体检](../labs/Lab6-低价VPS体检.md)

## 7.1 它可能是什么

结论：同样标着“2C2G / 固定 IPv4 / 几十元一年”，背后至少是五种完全不同的商品。先归位，再谈值不值。

| 来源 | 典型价格 | 成本怎么成立 | 你实际买到什么 | 主要风险 |
|---|---:|---|---|---|
| 大厂学生机/活动机的代实名转卖 | 20–60 元/年 | 卖家赚差价，或套取新用户补贴 | 一台本该属于别人的活动机 | 违反平台条款、随时回收、实名不是你 |
| 小 IDC 超售 VPS | 100–400 元/年 | 二手硬件 + 共享带宽 + 低线机房 | 一台共享资源的 VM | 晚高峰跑不满、售后慢、数据风险 |
| NAT 共享机 | 10–50 元/年 | 几十个用户共用一个公网 IPv4 | 一组端口，不是一个 IP | 端口受限、无法备案、被邻居牵连 |
| 动态 IP 伪装固定 IP | 30–80 元/年 | 拨号池 + DDNS，成本极低 | 会变的 IP + 一个域名 | 重启换 IP、解析滞后、无法做白名单 |
| 海外廉价 VPS | 70–260 元/年 | 国际 transit 便宜、IPv4 持有量大 | 一台国际线路的 VM | 回国慢、丢包、支付与合规问题 |

读法：前四种是“国内低价机”的主要来源，第五种是另一条成本曲线。它们的共同点是**价格低于 A 档成本地板**，区别在于从哪一项里省出来。

把价格放回三档模型（见 [05 成本解剖篇](./05-成本解剖篇.md) 5.6）：

| 档位 | 2C2G 年成本地板 | 30–60 元/年意味着什么 |
|---|---:|---|
| A 合规大厂 | 600 元 | 只有地板的 5%–10%，必然是获客补贴 |
| B 中小 IDC | 180 元 | 只有地板的 17%–33%，必须靠二手、超售、低线机房 |
| C 灰色超售 | 36 元 | 刚好压在地板上，任何一项涨价都会击穿 |

所以“30–60 元/年”这个价位，只可能来自三种情况：大厂补贴、灰色压缩、或者根本不是一台完整独立的机器。没有第四种。

## 7.2 “固定 IPv4”的三种真相

结论：广告里的“固定 IP”至少对应四种技术形态，只有第一种是大多数人理解的“独立固定 IPv4”。

| 形态 | 你怎么看到它 | 实际是什么 | 能否备案 | 典型月成本 |
|---|---|---|---|---:|
| 独立 IPv4 | `curl -4 ifconfig.me` 始终返回同一地址，且 whois 归属清晰 | 一个只分配给你的公网地址 | 可以（满足其他条件时） | 3–60 元 |
| 共享 IPv4 | IP 相同，但端口经常冲突、外部访问要加端口号 | 多个用户共用一个地址，靠端口区分 | 通常不可以 | 不到 1 元 |
| NAT 汇聚 | 只有内网地址，服务商做端口映射 | 你拿到的是“地址:端口”，不是 IP | 不可以 | 不到 1 元 |
| 动态 IP + DDNS | 重启后 IP 变化，域名自动更新 | 拨号池地址 + 动态解析 | 不可以 | 1–3 元 |

**先算一笔 IP 账。** IPv4 二级市场租用约 3.0–4.3 元/IP/月（快照 P-027，2026-11），折 36–52 元/年；国内一线城市 IDC 零售加一个 IP 可到 60 元/月（快照 P-032，2026-11）；大厂 EIP 保有费约 14.4 元/月（快照 P-030，2026-11）；海外头部云公网 IPv4 约 26 元/月（快照 P-029，2026-11）。

看到“30–60 元/年还带固定 IPv4”，先做减法：

```text
年价 48 元
− IPv4 成本 36–52 元（按批发价）
= 剩余 −4 ~ 12 元，还要覆盖 CPU、内存、硬盘、电力、带宽、运维
```

结论很直接：这个价格连一个批发 IP 都勉强，不可能再覆盖一台真实机器的其他成本。它要么是补贴，要么在 IP 上做了手脚，要么在别的地方等你还债。

三种常见的“还债”方式：

1. **首年低价、续费翻倍**。第一年 48 元，第二年 288 元，用迁移成本锁住你。
2. **低价引流、增项收费**。IP 单独收、带宽单独收、快照单独收、开机费单独收。
3. **超售到无法使用**。价格是真的，但晚高峰丢包、磁盘 IO 排队，实际不可用。

## 7.3 与大厂的 10 维对比

结论：低价机不是“更便宜的大厂”，而是另一类商品。它在价格上领先，在其余九维上大多落后。

| 维度 | A 合规大厂 | B 中小 IDC | C 灰色超售 | 你要看什么 |
|---|---|---|---|---|
| 合规 | IDC/ISP 齐全，可备案开票 | 部分有证，备案看机房 | 常无证，备案无门 | 许可证编号、合同主体 |
| 稳定 | SLA、冗余、故障赔付 | 无正式 SLA，靠口碑 | 无 SLA，随时消失 | 合同里的赔付条款 |
| 网络 | BGP 多线，有保证带宽 | 单线/假 BGP/共享 | 重度超售、达量限速 | 晚高峰 `mtr`、合同带宽 |
| 性能 | 新硬件，IO 有保障 | 新旧混用，邻居影响大 | 洋垃圾、磁盘排队 | `fio`、`smartctl` |
| 安全 | 安全组、快照、备份、DDoS 清洗 | 基础防护，备份自理 | 几乎无防护 | 快照是否免费、清洗阈值 |
| 服务 | 工单 7×24 | 工单慢，靠群 | 可能只有一个人 | 故障响应时间 |
| 计费 | 透明，控制台可查 | 套餐复杂，增项多 | 低价引流、层层加价 | 续费价、增项清单 |
| 生态 | 对象存储、CDN、数据库 | 少 | 无 | 是否需要配套 |
| 数据 | 多副本、快照、跨区 | 单盘为主 | 单盘、无备份 | 备份策略 |
| 风险 | 低 | 中 | 高 | 跑路成本 |

读法：这张表不是让你“别买低价机”，而是让你知道**自己放弃了哪九项**。如果这九项你都不需要，低价机就是合理的；只要有一项是刚需，就该换档。

## 7.4 适合谁 / 不适合谁

结论：低价机适合“可丢弃、可迁移、不承载他人数据”的场景；一旦涉及备案、发票、敏感数据、稳定在线，就不适合。

| 场景 | 是否适合 | 原因 | 替代方案 |
|---|---|---|---|
| 学习 Linux、练命令 | 适合 | 坏了重装即可，数据可丢 | 本地虚拟机 / 免费 PaaS |
| 临时项目、演示环境 | 适合 | 生命周期短，迁移成本低 | 按量付费 + 定时释放 |
| 海外访问、外贸展示 | 适合（选海外机房） | 免备案，线路可选 | 海外头部云免费层 |
| 个人博客（不备案） | 可以 | 但要接受线路与稳定性 | 静态托管 + CDN |
| 国内正式业务 | 不适合 | 备案、发票、SLA 都缺 | A 档轻量/ECS |
| 电商、支付、用户数据 | 不适合 | 数据安全与合规风险高 | A 档 + 备份 + 等保 |
| 需要开票报销 | 不适合 | 个人卖家开不了票 | A 档或正规 IDC |
| 要求 99.9% 在线 | 不适合 | 无 SLA、无冗余 | A 档多可用区 |

一条简单的判断：**这台机器明天消失，你会损失什么？** 如果只是几小时重装时间，可以买；如果有用户数据、备案主体、客户订单，不要买。

## 7.5 七大连坑

结论：低价机的坑有固定套路，按发生频率排，前三个占了大多数。

| 坑 | 怎么发生 | 早期信号 | 怎么防 |
|---|---|---|---|
| 超售 | 一台物理机切太多 VM，CPU 与磁盘排队 | 晚高峰 `%st` 高、IO wait 高 | 买前问超售比，买后连续 3 天高峰测 |
| IP 被墙 | 邻居违规，整段 IP 被牵连 | 国内直连超时、海外可通 | 选独立 IP、查 IP 历史、准备换 IP 方案 |
| 跑路 | 预收多年费用后失联 | 只支持年付、主体信息模糊 | 先月付、查经营主体、别预付多年 |
| 续费涨价 | 首年引流，续费回原价甚至更高 | 活动页不写续费价 | 下单前让客服书面确认续费价 |
| 隐性限速 | 标称 200M，达量后降到 1M | 合同写“公平使用” | 读达量限速条款，测月流量 |
| 无独立 IP | 实际是 NAT 或共享地址 | 外部访问要加端口 | `curl -4 ifconfig.me` + 端口测试 |
| 数据丢失 | 单盘、无快照、无备份 | 控制台没有快照功能 | 自己定时备份到对象存储 |

三个补充判断：

- **“不限量”通常配“达量限速”**。真正不限量的带宽成本极高，低价套餐一定在某个阈值后降速。
- **“独享”要落到合同**。广告里的“独享”可能指“独享端口”，不是“独享带宽”；只有合同写“最低保证带宽”才算数。
- **“原生 IP”不等于“干净 IP”**。IP 的历史滥用记录会影响解锁与服务可用性，买前用公开工具查一遍。

## 7.6 验机清单：硬件 / 性能 / 网络 / IP / 合规

结论：验机不是跑个分，而是用最小成本确认“它是不是它宣称的那台机器”。下面命令按五组排列，可直接复制。

### 硬件

```bash
# CPU 型号、核心数、是否被限制
lscpu | egrep 'Model name|CPU\(s\)|MHz'
nproc

# 内存与 Swap（低价机常靠 Swap 撑内存）
free -h
swapon --show

# 磁盘型号、通电时长、健康度
lsblk -d -o NAME,MODEL,SIZE,ROTA
sudo smartctl -a /dev/sda | egrep 'Model|Power_On_Hours|Reallocated|Pending'
sudo nvme smart-log /dev/nvme0 2>/dev/null | egrep 'percentage_used|data_units_written'

# 虚拟化类型：KVM 通常可改内核，OpenVZ/LXC 共享内核
systemd-detect-virt
```

判断：`Power_On_Hours` 超过 3 万小时、`Reallocated_Sector_Ct` 非 0、`percentage_used` 偏高，说明是高龄盘。`systemd-detect-virt` 返回 `openvz` 或 `lxc` 时，内核与内存不可控，很多测试会失真。

### 性能

```bash
# CPU 单核/多核
sudo apt install -y sysbench
sysbench cpu --cpu-max-prime=20000 run

# 磁盘 4K 随机与顺序写（注意：会写文件）
fio --name=rw --rw=randrw --bs=4k --size=512M --numjobs=1 --time_based --runtime=30 --group_reporting

# 内存带宽
sysbench memory --memory-block-size=1M --memory-total-size=2G run
```

判断：重点不是跑分高低，而是**晚高峰与凌晨的差异**。同一台机器两次测速差 30% 以上，说明邻居在抢资源。

### 网络

```bash
# 回程路由：看是否全程 59.43 / AS4809（CN2 GIA 的标志）
mtr -rwzc 20 1.1.1.1
traceroute -T -p 443 你的目标地址

# 带宽与丢包（需要另一台机器配合）
iperf3 -s            # 服务端
iperf3 -c 服务端IP -t 30 -P 4

# 晚高峰连续采样
for i in $(seq 1 10); do ping -c 20 1.1.1.1 | tail -1; sleep 60; done
```

判断：`mtr` 看每一跳的丢包是否集中在某一跳；`iperf3` 看是否能跑到标称值；连续 `ping` 看晚高峰是否规律性劣化。

### IP

```bash
# 出口 IP 与归属
curl -4 -s https://ipinfo.io
whois 你的IP | egrep 'org-name|country|netname'

# 端口是否真的对外开放（从外部机器执行）
nc -vz 你的IP 22
nc -vz 你的IP 443

# 是否被常见黑名单收录（示例，按需替换查询源）
curl -s "https://api.abuseipdb.com/api/v2/check?ipAddress=你的IP" -H "Key: 你的Key"
```

判断：出口 IP 与面板显示不一致，可能是 NAT；`whois` 归属是住宅宽带或不明组织，说明不是机房 IP；外部端口不通，说明有额外防火墙或 NAT。

### 合规

```bash
# 看服务商主体与许可证信息（在官网底部/关于页，不需要命令）
# 许可证查询（IDC/ISP）：https://dxzhgl.miit.gov.cn/ → 许可查询 → 输入企业名称
# 备案查询：https://beian.miit.gov.cn/ → 公共查询 → 输入域名
```

判断：查不到 IDC/ISP 许可证，就不能提供合规的机房托管与公网接入；查不到备案主体，国内网站随时可能被拦截。

### 人工六问

1. 续费价是多少，有没有书面锁定？
2. 带宽是独享还是共享，合同写不写“最低保证带宽”？
3. IP 是独立、共享还是 NAT，能不能给 whois 归属？
4. 超售比是多少，晚高峰能兑现标称的百分之多少？
5. 数据怎么备份，快照收不收费？
6. 支持几天无理由退款，跑路风险怎么承担？

六问里有两问答不上来，就该把它当“一次性玩具”，而不是生产环境。

## 7.7 购买建议

结论：低价机可以买，但要用“可丢弃”的方式买。下面五条是操作顺序，不是口号。

1. **先月付，后年付**。月付多花一点，换来一次完整的观察期；确认晚高峰、IO、售后都正常，再考虑年付。
2. **先小后大**。先买最低配验证线路与稳定性，不要一上来买高配或多年付。
3. **不存敏感数据**。不放用户隐私、不放唯一副本、不放生产密钥；重要数据至少两地备份。
4. **不用主邮箱、不绑主账号**。独立邮箱、独立密码、独立支付方式，降低被牵连的范围。
5. **保留迁移方案**。把部署写成脚本，数据定期导出，域名 TTL 提前调低；迁移时间按小时计，不按天计。

再加一条预算纪律：**把续费价写进预算表**。首年 48 元不是年成本，续费价才是；如果续费价未知，就按同档 A 档地板 600 元/年预留，避免第二年被动。

## 7.8 不点名原则：只讲类型和识别方法

结论：本篇不写任何低价机商家、店铺、群号或个人 ID。原因不是回避，而是这类商品的活动价与经营主体变化太快，点名等于给过期信息背书。

你要认的是特征，不是名字：

- 有 IDC/ISP 许可证，合同主体与收款主体一致；
- 活动页写明续费价、流量上限、达量限速规则；
- 控制台能查到资源到期时间、快照与备份功能；
- 支持月付、支持退款、工单有明确响应时间；
- IP 归属清晰，能提供 whois 与路由信息。

按“独立 IPv4 + 2C2G + 月付”这类条件去筛，再走一遍 7.6 的验机清单，比记商家名字可靠得多。头部公有云的公开定价与财报数据可以点名引用（如 05 篇的折旧表），但那只用于解释成本，不构成购买推荐。

## 本篇小结

- 几十元一年的“固定 IPv4”，先减 IP 成本：连批发 IP 都覆盖不了的价格，必然在补贴、超售或 IP 形态上做了文章。
- 固定 IP 有四种真相：独立、共享、NAT、动态；只有独立 IP 能满足备案与白名单需求。
- 低价机适合可丢弃的学习、演示、海外展示；涉及备案、发票、敏感数据、稳定在线，直接换 A 档。
- 买法五条：先月付后年付、先小后大、不存敏感数据、不用主账号、保留迁移方案。
