# 02 算账篇

> 一句话结论：同一个 AI 记账小工具，年成本可以从 0 元做到 1,000 元以上，差别不在代码写得多好，而在"有没有后端、有没有出网流量、要跑多久"。
> 读完你能：按自己的场景估出月成本 / 给每个场景挑出最低可行方案 / 认出报价单里被藏起来的那几笔钱。
> 对应总纲：2.1–2.7 ｜ 配套 Lab：Lab 1、Lab 2

## 2.1 贯穿案例：AI 记账小工具

先用一句话把结论放这儿：**决定你花多少钱的，不是你写了多少行代码，而是这个项目打开了哪几个"花钱开关"。** 同一个记账工具，关掉后端就是 0 元，打开数据库和 AI 调用就是每月几十元，再加上图片和大流量就直奔几百元。

### 案例长什么样

假设你用 AI 写了一个记账小工具，功能如下（这也是后面四种场景共用的底稿）：

| 功能 | 是否需要服务端 | 说明 |
|---|---|---|
| 记一笔：金额、分类、备注 | 否 | 纯前端就能做，数据存浏览器 |
| 月度报表：分类饼图、趋势 | 否 | 数据在本地，前端算 |
| 自然语言记账："昨天打车 38" | 是 | 要调 AI 接口，密钥不能放前端 |
| 拍照识别小票 | 是 | 要上传图片，要存储、要出网流量 |
| 多设备同步 / 分享给朋友 | 是 | 要有数据库和账号 |

用户规模也先定死：**自己 + 十个朋友，日活不到 20，数据量几千条、不到 100MB，晚上 9 点前后是高峰。** 这个规模很关键——它决定了你根本用不上"2 核 4G 起步"这种配置。

### 五个开关，决定你落在哪一档

这张表回答"我的项目该按哪一档算钱"。逐行对照，命中越多，成本越高。

| 开关 | 关着（省钱） | 打开（花钱） | 影响哪一项成本 |
|---|---|---|---|
| 服务端逻辑 | 纯静态 | 有接口、有常驻进程 | 计算 |
| 数据库 | 浏览器本地存储 | 云数据库 / 服务器上的库 | 计算 + 存储 |
| 文件与图片 | 无上传 | 图片、附件、导出文件 | 存储 + 流量 |
| 出网流量 | 几百 MB/月 | 每月几百 GB 起 | 流量（最容易失控） |
| 备案与合规 | 境外或纯静态 | 国内域名 + 服务器 | 时间成本 + 机器规格 |

### 四种部署路径速览

这张表是全文的骨架，先看结论再看推导。读法：年成本是量级区间，来自快照编号的组合，不是某一家厂商的报价单。

| 场景 | 典型形态 | 年成本量级 | 主要花钱项 | 对应小节 |
|---|---|---|---|---|
| A 静态页 | 作品集、落地页、纯前端工具 | 0 元 | 几乎没有 | 2.2 |
| B 带后端小工具 | 日活 <100，有库、有登录 | 0–400 元 | 计算 + 数据库 | 2.3 |
| C 流量型 | AI API 代理、图片站 | 100 元级到 1,000 元级以上 | 出网流量 | 2.4 |
| D 临时学习 | 装环境、跑 demo、学 Docker | 0–100 元 | 机时（按用多久算） | 2.5 |

### 后面每节的"成本卡"怎么读

四个场景统一用同一张卡片，五行固定：**需求 → 最低配置 → 月成本区间 → 更便宜的替代 → 踩坑点**。你不需要记住每家厂商的价格，只要记住这五行的填法，换任何项目都能自己算。

另外全文守两条口径：**首年价与续费价分开写**，流量费单独列。这两条是后面 2.7 节"常见误判"的源头，先记住。

## 2.2 场景 A：静态页/作品集/落地页 → 0 元

**结论：只要页面不需要在服务器上算东西，你就不该为它买服务器。用免费静态托管，月成本 0 元，唯一可能花钱的是自有域名。**

### 为什么能是 0 元

静态页就是一堆 HTML/CSS/JS 文件，访问时由 CDN 直接发出去，没有"程序在跑"，也就不需要 CPU 和内存。免费静态托管把这一步做成了默认能力：静态请求不限量、动态请求每日 10 万次以内免费，超限是要求升级而不是直接扣费（快照 P-022，2026-11）。

对比一下：同样一个作品集，买一台 2C2G 轻量，续费同价档首年 99 元、同价只给一次（快照 P-004，2026-11）；促销秒杀档首年 38 元，续费回到 600–720 元/年（快照 P-001，2026-11）。为了一个不跑程序的页面付这笔钱，等于给自行车买柴油。

### 成本卡

| 项目 | 内容 |
|---|---|
| 需求 | 纯前端页面；数据存浏览器 localStorage；不需要登录和数据库 |
| 最低配置 | 一台服务器都不需要；免费静态托管 + 免费 HTTPS |
| 月成本区间 | 0 元；如挂自有域名，域名费用另计（按注册商当年报价） |
| 更便宜的替代 | 本地打开 HTML 文件（0 元）；多个免费静态托管互为备份（0 元） |
| 踩坑点 | 免费版无 SLA；商用条款要看清楚；国内访问速度与备案；构建次数与文件大小限制 |

### 落地要点

1. **先确认它真是静态的。** 页面里只要出现"调用第三方接口拿数据"，那还是静态；一旦需要藏密钥、写数据库，就跳到 2.3。
2. **国内访问要单独测。** 免费托管的节点多在境外，国内打开慢是常态，这和"免费"是两件事，别混着骂。
3. **别急着买域名。** 先用托管商给的默认域名跑通，确认有人看，再考虑域名和备案。

对应实操：[Lab 1 静态作品集](../labs/Lab1-静态作品集.md)。

## 2.3 场景 B：带后端的小工具（日活 <100）→ 免费 PaaS / 轻量

**结论：日活 100 以内，免费 PaaS 加免费数据库基本够用，月成本 0–20 元；只有当你要备案、要常驻任务、要稳定在线时，才值得上轻量服务器，年成本 100–400 元。**

### 先看这个规模到底需要多少资源

日活 100、峰值几十个并发，2C2G 是绰绰有余的。真正卡你的不是 CPU，是三件事：数据库会不会休眠、函数有没有调用次数上限、以及免费层能不能商用。

### 三条路线，价格差一个数量级

| 路线 | 典型年成本 | 首年价 vs 续费价 | 适合谁 | 快照 |
|---|---|---|---|---|
| 免费 PaaS + 免费数据库 | 0 元 | 一直是 0 元；升级到付费档约 $20–25/月 | 自用、demo、内测 | P-023、P-024、P-026 |
| 国内轻量（续费同价档） | 99 元/年 | 同价续费仅 1 次，之后按原价（待核对） | 要备案、要固定 IP | P-004 |
| 国内轻量（促销秒杀档） | 首年 38 元 | 续费回到 600–720 元/年 | 抢得到、且能接受续费价 | P-001 |
| 中小 IDC（香港/精品线路） | 138–408 元/年，多为续费同价 | 首年≈续费 | 不想备案、能接受共享带宽 | P-011、P-013 |

读法：第一行是"用别人的免费额度"，第二行是"用补贴价买一台自己的机器"，第三行是"用可持续的低价买妥协"。三者的差别不在性能，在你愿意承担哪种不确定性。

### 成本卡

| 项目 | 内容 |
|---|---|
| 需求 | 登录、云数据库、每日定时任务、少量 AI 调用 |
| 最低配置 | 1C1G 或 2C2G；数据库 500MB 级；月流量 100GB 级 |
| 月成本区间 | 0 元（免费层）→ 约 8–12 元/月（99–138 元/年摊薄）→ 约 50–60 元/月（促销档按原价续费摊薄） |
| 更便宜的替代 | 把功能静态化（报表在前端算）；用 SQLite 单文件代替云数据库；用 Serverless 函数代替常驻进程 |
| 踩坑点 | 免费数据库闲置 7 天休眠（快照 P-024）；应用 15 分钟无请求休眠（快照 P-026）；函数每月 100 万次调用上限（快照 P-023）；Hobby 档禁止商用（快照 P-023） |

### 免费层不是"小号服务器"

免费 PaaS 的本质是"共享 + 休眠 + 限额"，它和一台 24 小时开机的服务器不是一回事：

- **冷启动**：15 分钟没请求就睡，第一个访问的人要等几秒（快照 P-026，2026-11）。
- **数据库休眠**：闲置 7 天后休眠，唤醒有等待（快照 P-024，2026-11）。
- **商用红线**：Hobby 档禁止商用，要商用得升到 $20/月，折合约 144 元/月（快照 P-023，2026-11，按 7.2 折算）。这一条最容易在"上线收钱"那天被忽略。
- **超限处理**：多数是限流或要求升级，不是悄悄扣费——这反而是好事，说明账单不会失控。

### 什么时候必须换成轻量服务器

四种情况，中一条就该换：要 ICP 备案；要跑常驻进程（爬虫、定时任务、WebSocket）；要绑定自己的固定 IPv4；免费层的休眠影响真实用户。

换的时候记住两笔账：**首年 99 元不等于长期 99 元**，续费同价往往只给一次（快照 P-004，2026-11）；能锁价到 2029–2030 的活动档是少数（快照 P-003，2026-11），买之前把续费规则读一遍。

参考成本地板：2C2G 在 B 档（中小 IDC）的年成本约 180 元，在 A 档（合规大厂）约 600 元（[三档成本模型](../_shared/三档成本模型.md)，量级估算）。所以 138 元/年的香港套餐略低于 B 档 2C2G 的年成本地板（约 180 元），差额靠共享带宽和超售兑现——能用，但晚高峰跑不满属于预期内的事，买前先按 [07 低价机篇](./07-低价机篇.md) 的方法验一遍。

对应实操：[Lab 2 全栈小工具](../labs/Lab2-全栈小工具.md)。

## 2.4 场景 C：AI API 代理/图片站（有出网流量）→ 流量费是大头

**结论：这类项目的 CPU 几乎不花钱，钱全在"数据从服务器往外送"这一项上。同样 300GB，放进流量包里 8 元/月，按流量计费就是 200 元上下——差 20 倍。**

### 先把"带宽"和"流量"分开

- **带宽**是水管粗细，单位 Mbps，决定同时能跑多快。
- **流量**是这个月用了多少吨水，单位 GB，决定账单多大。
- 换算：1 Mbps ≈ 0.125 MB/s；3M 峰值下载约 384 KB/s（[价格快照](../_shared/价格快照-2026-11.md)）。

代理和图片站的共同点是：**请求很小，响应很大**。文字 API 的返回可能只有几 KB，但一张图就是几百 KB。CPU 只负责转发，几乎不耗资源；真正被计费的是出网字节数。

### 出网流量到底多贵

这张表回答"我这个月要付多少流量费"。读法：入网通常免费，只有出网计费；按流量计费时才是大头。

| 月出网流量 | 按 0.65 元/GB 计（快照 P-053） | 按 0.8 元/GB 计，扣 20GB 免费额度（快照 P-054） |
|---|---:|---:|
| 50GB | 约 33 元/月 | 约 24 元/月 |
| 300GB | 约 195 元/月 | 约 225 元/月 |
| 1TB（1,024GB） | 约 666 元/月 | 约 805 元/月 |

同样是 300GB，买一台带 300GB/月 流量包的轻量，年付 99 元、折合约 8 元/月（快照 P-004，2026-11）。**这不是"哪家便宜"的问题，是计费模式的问题**：流量包把不确定性卖给了厂商，按流量计费把不确定性留给了你。

### 一个图片站的量级估算

每张图压缩到 200KB，日 5,000 次图片请求 = 1GB/日 ≈ 30GB/月；如果是 1 万 PV、每页 5 张图，就是 10GB/日 ≈ 300GB/月。后者按流量计费约 200 元/月，一年 2,400 元——比一台服务器贵得多。

### 成本卡

| 项目 | 内容 |
|---|---|
| 需求 | 转发 AI 接口请求；图片上传、外链、缩略图 |
| 最低配置 | 1C1G 足够；关键是选对计费方式（流量包 > 纯按流量） |
| 月成本区间 | 100GB 内约 0–65 元；300GB 级约 8–225 元（取决于计费方式）；1TB 级约 100–800 元 |
| 更便宜的替代 | 图片压缩 + 缩略图；开缓存头减少回源；静态资源放对象存储 + CDN；把大文件改成分片按需加载 |
| 踩坑点 | 流量被盗刷；缓存没设导致每次都回源；跨区/回源流量另计；免费额度超限自动转按量 |

### 三个必须提前做的事

1. **设流量上限或预算告警。** 流量型项目最怕的不是贵，是某天醒来发现被刷了几百 GB。
2. **给图片做压缩和缩略图。** 200KB 压到 60KB，流量直接降到三分之一，这是唯一"改代码就能省钱"的地方。
3. **把静态资源和 API 分开计费。** 图片走对象存储 + CDN，API 走小机器，两边的账单才看得清。

低价机专题里提到的"达量限速"条款，在这类项目上尤其要看：标称"不限量"后面往往跟着公平使用条款，超量后降到 1Mbps，等于站点半瘫。详见 [04 省钱篇](./04-省钱篇.md) 的成本刺客清单。

## 2.5 场景 D：临时学习/练手 → 按量 + 定时释放

**结论：学习用途按"用多久"付钱，不要年付。按量付费 + 用完释放 + 快照留底，两周的练手成本通常比一台年付机器还低，而且不会留下一年没人管的闲置机器。**

### 学习的成本结构和你以为的不一样

学习场景的需求是"这两周我要装环境、学 Linux、跑 Docker、试部署"，不是"这个服务要 7×24 在线"。所以真正该计费的是**机时**，不是**月份**。

包月/包年的机器，你只为其中几十个小时付费，剩下 700 小时在给你不用的东西交钱。按量付费贵在单价，便宜在只算实际用时。

### 成本卡

| 项目 | 内容 |
|---|---|
| 需求 | 1–2 周内装环境、跑 demo、学 Docker/Nginx/数据库 |
| 最低配置 | 1C1G 或 2C2G；系统盘 40GB；不需要高带宽 |
| 月成本区间 | 0 元（本地 WSL/Docker）→ 十几到几十元（按量，用几天就释放）→ 8–34 元/月（月付 B 档） |
| 更便宜的替代 | 本地虚拟机 / WSL（0 元）；学生认证机型约 26 元/年（快照 P-008，2026-11）；免费 PaaS 当练习场 |
| 踩坑点 | 关机不等于免费；忘记释放；快照越积越多；按量欠费；自动续费 |

### "关机不等于免费"到底扣什么

这是新手第一个被刺的地方。关机后停的通常只是 CPU 和内存，下面这些照扣：

- **云盘**：系统盘和数据盘按容量计费，关机照收。
- **公网 IP**：闲置同价，海外口径约 26 元/月（快照 P-029，2026-11）；国内 EIP 保有费约 14.4–14.6 元/月，闲置照收（快照 P-030，2026-11）。
- **快照**：按实际占用容量计费，删机器不删快照就一直计费。

所以正确的收尾动作是三步：**打快照 → 释放实例 → 删掉不需要的磁盘和 IP**。只做第一步，等于把机器换成了一张长期账单。

### 一条可执行的学习节奏

1. 第一天：本地跑通，确认真的需要一台远程机器。
2. 需要用的时候开按量，选最低配，装完环境立刻打快照。
3. 当天不用就释放实例，下次用快照恢复。
4. 学习结束，删快照、删磁盘、删 IP，回控制台确认账单归零。

## 2.6 每个场景的三档方案：0 元 / 低配 / 舒适

**结论：四个场景都有 0 元起点；"低配"是把钱花在必要项上，"舒适"买的是稳定和省心，不是性能。先跑 0 元档，卡住了再升，是更省钱的顺序。**

### 四场景 × 三档

这张表回答"我这个场景，三档分别长什么样、大概多少钱"。读法：年成本是量级，含首年优惠的已单独标注。

| 场景 | 0 元方案 | 低配方案（年成本） | 舒适方案（年成本） |
|---|---|---|---|
| A 静态页 | 免费静态托管（快照 P-022） | 免费托管 + 自有域名（域名费另计） | 免费托管 + 对象存储放图（按量计费） |
| B 带后端 | 免费 PaaS + 免费数据库（快照 P-023、P-024） | 轻量 2C2G，首年 99 元（快照 P-004） | 境外轻量 2C4G，199 元/年（快照 P-010） |
| C 流量型 | 前端托管 + 少量图片直出 | 轻量带 300GB/月 流量包，99 元/年（快照 P-004） | 境外 30M / 1.5TB，199 元/年（快照 P-010） |
| D 临时学习 | 本地 WSL / Docker | 月付 B 档，34 元/月（快照 P-013） | 大厂按量 + 快照，用几天算几天 |

### 三档的成本与代价对照

光看价格会选错，得把"你放弃了什么"一起看。

| 档位 | 年成本量级 | 你买到了什么 | 你放弃了什么 |
|---|---|---|---|
| 0 元 | 0 元 | 能用、能上线、能给别人看 | SLA、稳定唤醒、商用授权、固定 IP |
| 低配 | 99–408 元 | 一台自己的机器、固定 IPv4、可备案 | 续费可能涨价、带宽共享、售后一般 |
| 舒适 | 199 元起，上不封顶 | 更大带宽/流量、更快线路、更好售后 | 钱，以及"其实用不上"的那部分资源 |

### 首年价与续费价必须分开记

这是全篇最容易被忽略的一行字。同一个 2C2G：

- 促销档首年 38 元/年，续费回到 600–720 元/年（快照 P-001，2026-11）。
- 常规新用户价 68 元/年，续费同样回到 600–720 元/年（快照 P-002，2026-11）。
- 续费同价档 99 元/年，但同价通常只给 1 次（快照 P-004，2026-11）。
- 锁价档 99 元/年，活动期内续费同价，可锁到 2029–2030（快照 P-003，2026-11）。

所以做预算时写两个数：**第一年多少、第二年起多少**。只写一个数的预算表，第二年一定会被打脸。

### 流量费单独占一行

不管哪个场景，预算表里都把"流量"单列，不要并进"服务器"。

| 计费方式 | 典型形态 | 风险 |
|---|---|---|
| 固定带宽 | 3M/4M/5M 独享 | 速度上限低，但账单可预测 |
| 月流量包 | 300GB / 1TB / 1.5TB | 超量另计或限速，要盯用量 |
| 纯按流量 | 0.65–0.8 元/GB（快照 P-053、P-054） | 被刷就爆，必须有告警 |

## 2.7 成本估算公式与常见误判

**结论：把成本拆成"固定 + 流量 + 一次性"三块，再乘时间，误差就不会超过一倍；大多数"算错了"不是公式错，是把首年价当长期价、把带宽当流量、把关机当免费。**

### 一个够用的公式

```text
月成本 ≈ 固定资源费（计算 + 存储 + IP）
       + 流量费（月出网 GB × 单价）
       + 增值服务费（CDN、快照、备份、数据库托管）
       + 一次性费用 ÷ 12（域名、备案、迁移）

年成本 ≈ 月成本 × 12
首年成本 ≈ 年成本 − 首年优惠额（只减第一年，不要减到第二年）
```

流量估算用这条（来自快照换算口径）：

```text
月流量(GB) ≈ 带宽(Mbps) × 0.125 × 3600 × 24 × 30 ÷ 1024 × 利用率
例：5M 带宽、10% 利用率跑满一个月 ≈ 1.6TB
```

### 三分钟估算流程

1. **定档**：按 2.1 的五个开关，判断落在 A/B/C/D 哪个场景。
2. **定配置**：日活 <100 一律 2C2G 起，别被"推荐 4C8G"带跑。
3. **算固定**：年付价 ÷ 12，或月付价直接取。
4. **算流量**：估月出网 GB，乘单价；能用流量包就用流量包。
5. **加一次性**：域名、备案时间、迁移成本，摊到 12 个月里。
6. **写两个数**：首年、第二年起。写完再和成本地板比一次（[5.6 三档成本重算](./05-成本解剖篇.md#56-三档成本重算)）。

### 九个常见误判

这张表可以直接当自查清单用。左列是你可能说过的话，右列是它错在哪。

| 误判 | 实际 | 怎么算对 |
|---|---|---|
| "首年 99，一年就是 99" | 续费可能回原价 | 写首年价 + 续费价两个数 |
| "5M 带宽 = 5MB/s" | 5Mbps ≈ 0.625MB/s | 除以 8 |
| "我买的是 5M 带宽，流量随便用" | 带宽和流量是两回事 | 单独估月出网 GB |
| "关机就不花钱了" | 云盘、IP、快照照收 | 释放实例 + 删盘 + 删 IP |
| "CPU 越强越好" | 低流量项目计算不是大头 | 先看带宽和流量 |
| "IP 是送的" | 闲置 IP 也计费，国内约 14.4–14.6 元/月 | 不用就解绑释放 |
| "快照不要钱" | 快照按占用容量计费 | 定期删旧快照 |
| "免费额度够用" | 超限后限流或转按量 | 设预算告警，盯用量 |
| "流量不会被刷" | 图片站和代理最容易被刷 | 设上限 + 缓存 + 压缩 |

### 最后一句

算账的目的不是把成本压到最低，而是**知道自己在为什么付钱**。0 元方案能满足就先别买机器；买了机器就把续费价和流量费写进预算表；每一笔"比预期贵"的支出，都能在 05 篇的成本地板里找到解释。

## 本篇小结

- **先定场景再谈价格**：静态 0 元、带后端 0–400 元/年、流量型 100–1,000 元/年以上、临时学习按机时算，四档不要混着比。
- **两个数必须同时写**：首年价和续费价。只写首年的预算，第二年一定超。
- **流量单独列一行**：同样 300GB，流量包约 8 元/月，按流量计费约 200 元/月，差别在计费模式不在厂商。

## 本篇交付物

- 主交付物：四张场景成本卡（需求 / 最低配置 / 月成本区间 / 更便宜的替代 / 踩坑点），加一张四场景 × 三档方案对照表。
- 复用方式：把自己的项目按 2.1 的五个开关过一遍，落到某个场景，抄对应成本卡，把"最低配置"和"月成本区间"两行换成自己的数字；再用 2.7 的公式补上流量费。
